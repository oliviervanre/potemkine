# Potemkine — Kuberniet

Console d’administration fictive et satirique consacrée à une usine logicielle volontairement tentaculaire.

Modules : Kubernetes, chaînes CI/CD, giga-calculateur, supervision quantique, énergie, conformité, supervision des superviseurs et monitoring cardiaque du chef de projet.

Le prototype utilise React/Vinext pour sa version exécutable. Les données sont entièrement simulées.
